# Lifelong Vibe — A3 wall poster set

Six coordinated wall posters selected from the approved `lifelong-vibe-proof`
illustrations.

## Print specification

- Canvas: A3 portrait, 3508 × 4961 px
- Resolution metadata: 300 DPI
- Mat color: warm ivory `#F8F3E8`
- Treatment: proportional enlargement plus an ivory paper mat
- Source art: unchanged; no generative face redraw, inpainting, or facial retouching
- Suggested paper: 200–250 gsm matte fine-art paper
- Suggested frame: natural oak, walnut, or thin black with no additional digital crop

## Identity gate

Face consistency is protected by preserving every pixel of the selected approved
source illustrations. The conversion only scales the complete source image and
adds the outer A3 mat. If a printer requests bleed, add bleed outside this canvas;
do not crop into the illustration or regenerate either face.
