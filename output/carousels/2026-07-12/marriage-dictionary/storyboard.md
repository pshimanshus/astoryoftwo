# Shaadi Dictionary

Status: copy locked, seven-slide proof series ready for direction review.

## Setup

This carousel is an illustrated shaadi dictionary: ordinary Hinglish phrases
whose meaning changes after living as a couple. The format is funny first, then
soft by the end. Each slide must work as a tiny scene, not a definition card.
The main word/phrase should be only slightly bigger than the meaning line. The
scene should carry most of the communication.

## Locked Copy And Visuals

1. **SHAADI / DICTIONARY**  
   Open dictionary / home surface, both leaning in like they are co-writing it.

2. **BAS 5 MIN / = 40 min + last look**  
   Doorway scene. Zuv waits with keys and phone; Aachu is still doing one last
   getting-ready action through a mirror or doorway.

3. **MERA CHARGER / = tumhare bag mein**  
   Aachu's open bag contains Zuv's charger. Zuv sees it with mock
   betrayal.

4. **MIL NAHI RAHA / = ek drawer checked**  
   Drawer search. Aachu knows the place; Zuv has checked one drawer and is
   already defeated. Playful, not foolish.

5. **THEEK HAI / = paani rakh diya**  
   Tiny after-fight silence. A glass of water is kept where the other will find
   it.

6. **CHALO / = bills + dessert bhi**  
   Grocery list, bill receipt, and dessert box. Shared adulting with one
   unnecessary treat.

7. **GHAR / = same words, new meanings**  
   Final home tableau with migrated objects, water glass, list, dessert, open
   dictionary, and the couple close together.
