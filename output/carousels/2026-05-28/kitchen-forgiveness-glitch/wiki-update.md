# Wiki Update Draft

## Learning

For daily human comedy, @a.storyof.two carousel packages should be built as
scene-cut stories before any slide copy is written.

This package applies the new baseline:

- story first;
- storyboard first;
- visual drama before copy;
- thought/speech bubbles as tiny props;
- no moralized relationship thesis;
- final images blocked until creator approves the scene sequence.
