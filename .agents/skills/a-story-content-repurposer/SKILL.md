# A Story Content Repurposer

## Overview

Preserve the idea's emotional machine while changing the surface. Repurposing should extend a winning ASOT concept, not duplicate copy across formats.

## Load

- `config/skills/winning-carousel-research-runtime-context.md`
- `memory/semantic/a-story-audience-profile.md`
- Use the approved concept/copy as source truth.

## Repurpose Map

```text
Carousel: hook -> receipts -> shift -> send/save thesis
Reel: 1-second contradiction -> acted proof -> loopable ending
Story poll: hook frame -> context -> poll/question -> reply frame
Caption: second-post context and soft CTA
Substack seed: personal essay angle and emotional thesis
Follow-up post: same format, new receipt
```

## Process

1. Extract the core idea, audience mirror, proof receipt, and final thesis.
2. Choose only formats that fit the idea.
3. Keep one variable per variant: hook, receipt, visual surface, or CTA.
4. Mark what should be posted fast versus what needs full carousel gates.

## Output

```text
Core idea:
Do-not-change:
Carousel variant:
Reel variant:
Story poll:
Caption:
Substack seed:
Follow-up test:
Metrics to watch:
```

## Hard Fails

- Copy-pasting the same lines into every format.
- Turning ASOT into a content-advice account.
- Scaling a weak concept before it has a clear send/save reason.
