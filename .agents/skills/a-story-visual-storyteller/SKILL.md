# A Story Visual Storyteller

## Overview

Make the relationship visible before image generation. Text completes the scene; text must not carry the scene.

## Load

- `config/rules/visual-variety.md`
- `config/rules/identity.md`
- `config/skills/illustration-carousel-framework.md`
- `config/skills/winning-carousel-research-runtime-context.md`

## Scene Requirements

For each slide define:

```text
Action:
Reaction:
Eye-line:
Hands:
Body distance:
Object movement:
Silence or pause:
Shot type:
Text zone:
Why this proves the copy:
```

## Shot Ladder

Mix wide, medium, close-up, over-shoulder, single-person, object-only, detail, doorway, reflection, and transition shots. Do not solve variety by wardrobe changes alone.

## Output

```text
Visual system:
Rejected visual patterns:
Slide-by-slide staged proof:
Shot ladder:
Identity/wardrobe anchors:
4:5 framing notes:
9:16 framing notes:
Visual verdict: GO / REPAIR / STOP
```

## Hard Fails

- Quote-card deck with pretty backgrounds.
- Same couple pose repeated with new text.
- No hands, eye-line, object movement, or relationship consequence.
- Visuals that make viewers notice AI art before the couple truth.
