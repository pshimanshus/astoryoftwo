last_updated: 2026-09-04
status: compatibility_pointer

This legacy skill reference is not a prompt authority. Active generation uses:

- `config/references/a-story-illustration-master-prompt.md` for the structural
  prompt skeleton;
- `config/carousel_style_contract.json` for the one active illustration style
  prompt, negative prompt, board path, and board SHA-256;
- `config/rules/palette.md` and `config/rules/visual-variety.md` for normative
  finish and cinematic direction;
- `config/rules/identity.md` for actual-photo identity requirements; and
- `config/rules/image-dimensions.md` for request-derived native canvases.

Do not restore the retired embedded style paragraph, obsolete portrait canvas, large
reference packet, multi-room process, or free-form style/reference selection
formerly recorded here. The current production path keeps exactly four public
gates, attaches exactly four selected actual identity photos plus the one
hash-bound active style board, defaults to native 1080x1440, and emits
1080x1920 or 1080x1080 only when explicitly requested.
