Architecture Check

Mostly correct

The seven layers are valid as an ecosystem map. For a carousel jam, the actual runtime is not top-to-bottom: Layers 1-3 feed memory, Layer E sharpens the story, Layer C builds the package, and image generation/QA finish it. Layer D and Layer 0 are sibling workflows, not required steps for final illustrations.

What is executable today The C-layer default path is real: scripts/create_illustration_carousel.py routes to pipeline/stages/codex_native_carousel.py, writes the carousel package, and can prepare image handoff.
What is background infrastructure The source/wiki/pipeline layers are how the system learns from Instagram and stores memory. They are not rerun every time you jam unless you explicitly run the analysis pipeline.
Where final images can block Prompt handoff is not the same as final art. The package becomes publishable only after native generated images, packaging, visual QA, and final-audit.json pass.

Seven Layers, Corrected For Runtime

The architecture is right as a layered content system. The correction is to distinguish always-on context, optional sibling workflows, and the actual carousel execution path.

Layer E

Romance Story Selling Canon

Pre-concept lens: obstacle, proof, reversal, payoff, story-selling score.

config/skills/romance-story-selling-engine.md + config/references/story-selling-canon/

scripts/create_substack_article_package.py

Illustrated Carousel

The runtime path for one idea: C1-C6 package, prompt pack, visual gates, image handoff.

scripts/create_illustration_carousel.py + pipeline/stages/codex_native_carousel.py
Layer 0

Pre-Post Reel Analysis

Sibling workflow that evaluates planned Reels before posting.

scripts/analyze_prepost.py
Layer 1

Sources

Instagram posts, reels, captions, hashtags, comments, and scrape outputs.

pipeline/stages/a1_ingest.py + corpus/
Layer 2

Wiki and Memory

Reusable knowledge: themes, insights, carousel memory, working state.

wiki/ + memory/ + pipeline/agentic/
Layer 3

Analysis Pipeline

A1-A5 scrape, parse, analyze, build wiki, report. It feeds the memory layer.

pipeline/stages/a1_ingest.py ... a5_report.py

Actual carousel runtime

Input idea -> context and memory -> Layer E -> golden-theme tournament -> story director -> C-layer package -> visual gates -> image handoff -> generated images -> QA -> closeout.

Rules are canonical

config/rules/*.md is the source of truth. Skills and references can repeat text, but when there is disagreement, the rules folder wins.

Default runtime

codex-native is the default. It does not require Anthropic for normal carousel packages. The legacy anthropic route still exists behind --mode anthropic.

Done means final assets

A package with prompt-pack.json is not done. Done means final/, final-reels-stories/, final-images.json, visual-qa.md, and final-audit.json.

Artifact Lifecycle

The package directory is the audit trail. Each group below answers: what evidence exists, what the gate proves, and what the next step can trust.

Concept Evidence

  • layer-e-story-selling.jsonStory-selling score, card, selector decision.
  • concept-selection.jsonGolden-theme route selection when a tournament is recorded.
  • concept.jsonHuman truth, emotional arc, visual style, story director gate.
  • storyboard.mdReadable story spine and slide flow for creator review.

Copy and Visual Gates

  • slides.jsonSlide-by-slide copy, visual, source image, identity continuity.
  • copy.jsonCaption, alt text, hashtag package, posting notes.
  • post-copy-visual-room.jsonVisual-system winner after copy approval.
  • visual-debate.jsonEvidence/romance/continuity council verdict.
  • visual-plan-quality.jsonPer-slide GO/REPAIR/STOP before image generation.

Identity and Prompts

  • identity-dossier.jsonSelected identity bundle and generation references.
  • identity-face-contact-sheet.jpgReference image input required for generation.
  • identity-generation-preflight.mdHuman-readable identity checks before image work.
  • identity-consistency-review.jsonFace, clothing, expression, and continuity gate.
  • prompt-pack.jsonShared style plus one prompt per slide.

Final Output and QA

  • codex-image-prompts/Generator-ready prompts for both native formats.
  • image-generation.jsonDraft, blocked, handoff, proof, or generated status.
  • final/Native 4:5 Instagram post upload PNGs.
  • final-reels-stories/Separate native 9:16 Reels/Stories PNGs.
  • visual-qa.mdFinal image review notes and failed checks.
  • final-audit.jsonPublishability gate used by state derivation.

Package State Machine

pipeline/agentic/carousel_state.py derives the state from package artifacts. This is the quick answer to "where are we right now?"

draftPackage is incomplete or only starting.
copy_lockedprompt-pack.json or copy.json exists.
handoff_readyPrompts and blocker file exist; generate with identity refs.
proof_readyA proof slide exists and needs approval or repair.
partial_finalGenerated signals exist; run visual QA and audit.
publishablefinal-images.json publishable and final-audit.json passed.

File and Folder Call Map

"Called" means one of four things: runtime import, context read, agent/skill reference, or output write. This table keeps those meanings separate.

Surface How It Is Used Purpose When You See It
AGENTS.md Context read Operating contract, layer definitions, mandatory gates, closeout rule. Start of every repo session.
config/rules/ Context read via manifest Canonical palette, identity, text, brandmark, brand-zone, voice, golden-theme, story-selling rules. Before any carousel writing, prompting, or generation.

config/skill-systems.json Runtime/context config Names workflow systems such as carousel_jam, their components, agents, gates, and artifacts. When resolving the carousel jam system or explaining the workflow.
wiki/, memory/, output/reports/ Context read and learning store Provides standards, successful-theme evidence, creator preferences, and latest working memory. Before concept recommendation and after substantial runs.
config/skills/*.md Agent/skill reference Operating playbooks for jam autopilot, Layer E, golden theme, story director, and visual framework. During ideation, copy, visual planning, and generation handoff.
agents/*.md Agent/skill reference Role prompts for story, visual, identity, prompt, copy, review, and post-copy visual rooms. When the room is run by parallel agents or simulated named reviewers.
scripts/create_illustration_carousel.py Runtime entrypoint CLI that chooses codex-native or anthropic mode, parses story/images, and prints package state. When turning an idea/story into a package.
pipeline/stages/codex_native_carousel.py Runtime import Default no-API package builder: title, identity selection, Layer E, lanes, slides, visuals, package write. Normal carousel creation.
pipeline/stages/carousel_visual_rooms.py Runtime import Builds post-copy visual room, visual debate, and visual-plan-quality artifacts. After copy approval and before image handoff.

pipeline/stages/carousel_quality.py Runtime import Writes run ledger, stage reviews, visual QA, wiki update, and final audit. After package build and after generated outputs are packaged.
pipeline/agentic/checks/ Deterministic checks Palette, OCR text, image size, and prompt-constraint gates. When visual QA or automated gates are run.
scripts/autopublish.py Closeout entrypoint Runs risk scans, tests, wiki health, commit, and push for substantial file-changing sessions. End of a substantial repo-editing session.
