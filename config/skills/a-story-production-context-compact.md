# A Story Production Context Compact

Use this as the required production context. Open the referenced rule files only
when the task needs their full wording.

## Production Gates

- Default post/carousel output is native `1080x1440`.
- Generate `1080x1920` or `1080x1080` only when explicitly requested.
- Keep a tiny `@a.storyof.two` brandmark on requested outputs.
- Aachu and Zuv must stay recognizable across face, hair, height, build,
  posture, expression, and clothing style.
- Final art needs real identity/style references or an explicit note that they
  are unavailable.
- Wardrobe comes from current attached photos before any static outfit menu.
- Visible text must match locked copy exactly, unless a documented text
  exception exists.
- Avoid invented text, extra captions, fake UI, watermarks, generic quote-card
  layout, and repeated posing beside the line.
- Use warm ivory paper and controlled watercolor-and-ink styling; avoid yellow,
  mustard, sepia, parchment, tan, beige, and generic AI warmth.
- Every slide should change knowledge, pressure, choice, relationship position,
  object state, or meaning.
- Check prop ownership, body mechanics, visible hands, gaze, distance, and scene
  continuity before accepting pixels.
