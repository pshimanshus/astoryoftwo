# A Story Ideation Context Compact

Use quietly for small concept, copy, recall, and jam requests.

- Protect the lived couple moment. The idea should make someone think "this is
  me", "this is her", or "this is us".
- Start with the alive human draft before scoring, agents, or packaging.
- Show change: before -> pressure or choice -> after.
- Ground the change in a receipt: action, object state, gaze, silence, distance,
  consequence, or tiny behavior.
- Choose the strongest native form instead of manufacturing derivatives.
- Public voice is warm, personal, specific, first-person when posting from the
  channel, and never coachy, clinical, listicle, or generic quote-card.
- Use one Hinglish line only when it sounds spoken.
- Open `config/rules/voice.md`, `config/skills/creator-skill-stack.md`, or
  `.agents/skills/a-story-storytelling-hook/SKILL.md` only when the task needs
  full wording.
